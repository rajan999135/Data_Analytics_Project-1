# Retail Customer Analytics Dashboard

## Project Overview
This project is a complete end-to-end Data Analytics solution built using PostgreSQL, SQL, Python, and Dash. The objective of this project was to analyze retail customer purchasing behavior, identify important business trends, and generate actionable insights through advanced SQL analysis and interactive dashboard visualizations.

The project focuses on solving real-world business problems related to:
- Customer segmentation
- Product performance analysis
- Discount optimization
- Subscription conversion analysis
- Customer loyalty tracking

An interactive Python Dash dashboard was developed to present insights in a user-friendly and visually engaging way for both technical and non-technical stakeholders.

---

# Key Insights

- Young Adults generated the highest overall revenue.
- Repeat buyers showed significantly higher subscription conversion rates.
- Some products appeared heavily over-discounted, reducing potential profitability.
- Loyal customers contributed strong repeat purchase behavior.
- Highly rated products can improve trust and increase conversions.

---

# Business Recommendations

## Invest in Young Adults
Target personalized marketing campaigns and product strategies toward the Young Adult segment.

## Convert Repeat Buyers
Implement automatic subscription offers after 5 purchases to increase conversion rates.

## Refine Discount Strategy
Audit products with high discount frequency and test reduced discount strategies to improve profitability.

## Reward Loyal Customers
Launch a VIP rewards program for customers with 10+ purchases.

## Promote Top-Rated Products
Use highly rated products as social proof in marketing campaigns and featured placements.

## Expand Dataset for Future Analysis
Include date and time information to support:
- Seasonal trend analysis
- Cohort retention analysis
- Revenue forecasting
- Time-series analysis
